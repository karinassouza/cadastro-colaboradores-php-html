# Cadastro de Colaboradores

Sistema de cadastro de colaboradores desenvolvido como atividade acadêmica, utilizando **HTML, CSS e PHP**.

Sobre o projeto

O projeto consiste em um formulário para cadastro de novos colaboradores. Após o preenchimento e envio do formulário, os dados são recebidos e processados por um arquivo PHP, que apresenta as informações cadastradas em uma página de confirmação.

Tecnologias utilizadas

* HTML5
* CSS3
* PHP
* XAMPP

Funcionalidades

* Cadastro do nome completo;
* Cadastro da idade;
* Cadastro da profissão;
* Cadastro do salário pretendido;
* Cadastro da experiência anterior;
* Processamento dos dados utilizando PHP;
* Exibição dos dados cadastrados.

Estrutura do projeto

```text
cadastro-colaboradores
├── cadastro.html
├── processaCadastro.php
└── style.css
```

Como executar

Para executar o projeto localmente:

1. Instale o **XAMPP**.
2. Coloque a pasta do projeto dentro da pasta `htdocs` do XAMPP.
3. Inicie o **Apache** pelo painel do XAMPP.
4. Abra o navegador.
5. Acesse:

```text
http://localhost/cadastro-colaboradores-php-html/cadastro.html
```

Finalidade

Projeto desenvolvido para fins acadêmicos, com o objetivo de praticar a criação de formulários HTML, estilização com CSS e processamento de informações utilizando PHP.
